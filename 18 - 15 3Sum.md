# Two Pointers
```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        // Step 1: Sort the array so we can use two pointers
        sort(nums.begin(), nums.end());
        vector<vector<int>> res;

        // Step 2: Fix the first number one by one
        for (int i = 0; i < nums.size(); i++) {
            // If first number > 0, stop because sum will always be > 0
            if (nums[i] > 0) break;

            // Skip duplicate first numbers
            if (i > 0 && nums[i] == nums[i - 1]) continue;

            // Step 3: Two-pointer approach for the remaining part
            int l = i + 1, r = nums.size() - 1;
            while (l < r) {
                int sum = nums[i] + nums[l] + nums[r];

                if (sum > 0) {
                    r--; // decrease sum
                } 
                else if (sum < 0) {
                    l++; // increase sum
                } 
                else {
                    // Found a triplet
                    res.push_back({nums[i], nums[l], nums[r]});
                    l++;
                    r--;

                    // Skip duplicate second numbers
                    while (l < r && nums[l] == nums[l - 1]) {
                        l++;
                    }
                }
            }
        }
        return res;
    }
};
```

---

## Library Function Definitions

* `sort(nums.begin(), nums.end())`: Sorts the array in ascending order.
* `vector<vector<int>>`: A 2D vector to store all valid triplets.

---

## Time & Space Complexity

| Metric   | Complexity               | Reason                                                             |
| -------- | ------------------------ | ------------------------------------------------------------------ |
| ⏱ Time   | `O(n^2)`                 | Outer loop `O(n)`, inner two-pointer `O(n)`                        |
| 💾 Space | `O(1)` (ignoring output) | Only a few variables, result storage depends on number of triplets |

---

## Step-by-Step Strategy

1. **Sort the array** to make duplicate removal and two-pointer search possible.
2. **Fix one number (nums\[i])** at a time as the first element of the triplet.
3. Use **two pointers (`l` and `r`)** to find two other numbers that make the sum zero.

   * If sum < 0 → move `l++` to increase sum.
   * If sum > 0 → move `r--` to decrease sum.
   * If sum == 0 → store the triplet, then skip duplicates.
4. **Skip duplicates** to avoid repeating triplets.
