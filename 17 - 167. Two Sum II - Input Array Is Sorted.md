# Two Pointers
```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& numbers, int target) {
        int l = 0, r = numbers.size() - 1; // two pointers at start and end

        while (l < r) {
            int curr = numbers[l] + numbers[r]; // sum of values at two pointers

            if (curr < target) {
                l++; // move left pointer right to increase sum
            }
            else if (curr > target) {
                r--; // move right pointer left to decrease sum
            }
            else {
                return {l + 1, r + 1}; // 1-based index as per problem
            }
        }
        return {}; // no valid pair found
    }
};
```

---

## Library Function Definitions

* `vector<int>`: C++ STL dynamic array.
* `numbers.size()`: Returns the size of the `numbers` vector.

## Time and Space Complexity

| Metric   | Value  | Reason                               |
| -------- | ------ | ------------------------------------ |
| ⏱ Time   | `O(n)` | Each element is visited at most once |
| 💾 Space | `O(1)` | No extra space used beyond variables |

---

## Step-by-Step Strategy for Solving

1. **Understand the constraint**: The input array is sorted in non-decreasing order.
2. **Initialize two pointers**: One at the start (`l`), one at the end (`r`).
3. **Loop while l < r**:

   * Calculate `curr = numbers[l] + numbers[r]`.
   * If `curr < target`, we need a larger sum → move `l++`.
   * If `curr > target`, we need a smaller sum → move `r--`.
   * If `curr == target`, return the indices (`l + 1`, `r + 1`) as required.
4. **If loop ends without return**, return empty array.
