# 📌 Problem Statement

You are given an `m x n` matrix where:

* Each row is sorted in **ascending order**.
* The **first integer** of each row is greater than the **last integer** of the previous row.

Write a function to check whether a given integer `target` exists in the matrix.
Return `true` if it exists, otherwise `false`.

---

class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int l = 0, r = matrix.size() - 1;

        // First binary search to find the possible row
        while (l <= r) {
            int m = l + (r - l) / 2;

            if (matrix[m][0] > target) {
                r = m - 1;
            }
            else if (matrix[m][0] < target) {
                l = m + 1;
            }
            else {
                return true; // found at first column
            }
        }

        // After loop: r points to the row where target could exist
        if (r < 0) return false; // target smaller than matrix[0][0]
        int row = r;

        // Second binary search inside the row
        l = 0, r = matrix[row].size() - 1;
        while (l <= r) {
            int m = l + (r - l) / 2;

            if (matrix[row][m] > target) {
                r = m - 1;
            }
            else if (matrix[row][m] < target) {
                l = m + 1;
            }
            else {
                return true;
            }
        }

        return false;
    }
};

# 🧠 Binary Search

```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        // Number of rows and columns
        int ROWS = matrix.size();
        int COLS = matrix[0].size();

        // Step 1: Binary search to find the correct row
        int top = 0, bot = ROWS - 1;
        while (top <= bot) {
            int row = (top + bot) / 2;

            // If target is greater than the last element of this row → move down
            if (target > matrix[row][COLS - 1]) {
                top = row + 1;
            }
            // If target is smaller than the first element of this row → move up
            else if (target < matrix[row][0]) {
                bot = row - 1;
            }
            // Otherwise, target must be inside this row
            else {
                break;
            }
        }

        // If no valid row was found
        if (!(top <= bot)) {
            return false;
        }

        // Step 2: Binary search inside the identified row
        int row = (top + bot) / 2;
        int l = 0, r = COLS - 1;
        while (l <= r) {
            int m = (l + r) / 2;

            if (target > matrix[row][m]) {
                l = m + 1; // Move right
            } 
            else if (target < matrix[row][m]) {
                r = m - 1; // Move left
            } 
            else {
                return true; // Found target
            }
        }

        // Not found
        return false;
    }
};
```

## 🧾 Library Function Definitions

Your code doesn’t use extra libraries beyond `vector`, which comes from **C++ Standard Template Library (STL)**:

* `std::vector<T>`: Dynamic array that can grow/shrink.
* `matrix.size()`: Returns number of rows.
* `matrix[0].size()`: Returns number of columns.

---

## 📈 Time & Space Complexity

* **Row binary search**: `O(log ROWS)`
* **Column binary search**: `O(log COLS)`
* **Total Time Complexity**: `O(log ROWS + log COLS)`
* **Space Complexity**: `O(1)` (only a few extra variables).

---

## 🪜 Step-by-Step Strategy

1. **Find candidate row**:

   * Use binary search on the first and last elements of rows.
   * If `target` lies within the range of row `i` (`matrix[i][0] ≤ target ≤ matrix[i][COLS-1]`), then it must be in that row.

2. **Search within row**:

   * Apply binary search again on that row to check if `target` exists.

3. **Return result**:

   * If found → `true`.
   * If not found → `false`.

# 🧠 Binary Search (One Pass)

```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int ROWS = matrix.size();
        int COLS = matrix[0].size();

        // Treat the matrix as a single sorted array of size ROWS * COLS
        int l = 0, r = ROWS * COLS - 1;

        while (l <= r) {
            int m = (l + r) / 2;

            // Map the 1D index 'm' back to 2D row & col
            int row = m / COLS;   // row index
            int col = m % COLS;   // column index

            if (matrix[row][col] == target) {
                return true; // Found target
            }
            else if (matrix[row][col] < target) {
                l = m + 1; // Move right in the virtual 1D array
            }
            else {
                r = m - 1; // Move left in the virtual 1D array
            }
        }

        return false; // Not found
    }
};
```

---

## 🧾 Library Function Definitions

* `std::vector<T>`: Dynamic array (from C++ STL).
* `matrix.size()`: Number of rows.
* `matrix[0].size()`: Number of columns.

No external libraries are required.

---

## 📈 Time & Space Complexity

* **Time Complexity**: `O(log(ROWS * COLS))` = `O(logN)` where `N = ROWS * COLS`.
* **Space Complexity**: `O(1)` (only a few variables used).

This is slightly more optimal than the **two-step row + column search** because it performs only **one binary search**.

---

## 🪜 Step-by-Step Strategy

1. Flatten the 2D matrix into a 1D array of size `ROWS * COLS`.

   * Virtual index mapping:

     * `row = m / COLS`
     * `col = m % COLS`

2. Perform **binary search** directly on the 1D range `[0, ROWS*COLS - 1]`.

3. Check:

   * If `matrix[row][col] == target` → return `true`.
   * If smaller → search right half.
   * If larger → search left half.

4. Return `false` if not found.

---

## 🎯 Visualization with Example

Example:

```
matrix = [
  [1, 3, 5, 7],
  [10, 11, 16, 20],
  [23, 30, 34, 60]
]
target = 16
```

* `ROWS=3, COLS=4 → total elements = 12`
* Flattened as: `[1,3,5,7,10,11,16,20,23,30,34,60]`

Binary Search:

* `l=0, r=11` → `m=5` → `matrix[5/4][5%4] = matrix[1][1] = 11` → too small.
* Move `l=6`.
* `m=8` → `matrix[8/4][8%4] = matrix[2][0] = 23` → too big.
* Move `r=7`.
* `m=6` → `matrix[6/4][6%4] = matrix[1][2] = 16` → ✅ Found!

---

✨ Key Difference vs Previous Method:

* **Row + Column Binary Search** → `O(log ROWS + log COLS)`
* **Flattened Matrix Binary Search** → `O(log(ROWS * COLS))` (cleaner + slightly simpler).
